# Noto Emoji

`NotoEmoji.ttf` is the unmodified monochrome Noto Emoji variable font
(`NotoEmoji[wght].ttf`) from Google Fonts, bundled at its default weight.
The terminal uses its outlines as foreground-colored glyph masks.

- Source: https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoemoji
